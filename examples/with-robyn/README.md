# Robyn and FastUI

> See [Other web frameworks](../../docs/tutorial/08-other-frameworks.md) in the tutorial for how the framework examples compare.

This is a simple example project that shows how to use FastUI with Robyn.

Is it possible?

Well README file at the FastUI repository says so, but we need to try it...

## How to run

### Clone the repo

```shell
git clone https://github.com/hasansezertasan/fastui-tutorials.git
cd fastui-tutorials
```

### Change directory to the example

```shell
cd examples/with-robyn
```

### Run the application

```shell
uv run with-robyn
```

Then open `http://127.0.0.1:8000`.
