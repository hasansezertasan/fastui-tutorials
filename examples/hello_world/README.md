# Hello World

> This example is explained step by step in the [tutorial](../../docs/tutorial/02-hello-world.md).

This is a simple hello world example built with FastUI.

Used Components:

- `Heading`

## How to run

### Clone the repo

```shell
git clone https://github.com/hasansezertasan/fastui-tutorials.git
cd fastui-tutorials
```

### Change directory to the example

```shell
cd examples/hello_world
```

### Run the application

```shell
uv run hello-world
```

Then open `http://127.0.0.1:8000`.
