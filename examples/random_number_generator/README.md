# Random Number Generator

This is a simple random number generator.

Used Components:

- `PageTitle`
- `Navbar`
- `Page`
- `Heading`
- `Div`
- `Paragraph`
- `Button`
- `ServerLoad`

Used Events:

- `GoToEvent`
- `PageEvent`

## How to run

### Clone the repo

```shell
git clone https://github.com/hasansezertasan/fastui-tutorials.git
cd fastui-tutorials
```

### Change directory to the example

```shell
cd examples/random_number_generator
```

### Run the application

```shell
uv run random-number-generator
```

Then open `http://127.0.0.1:8000`.
