# Flask and FastUI

> See [Other web frameworks](../../docs/tutorial/08-other-frameworks.md) in the tutorial for how the framework examples compare.

Flask and FastUI is a simple example project that shows how to use FastUI with Flask.

Is it possible?

Well, the answer at pydantic/FastUI#85 says "yes", but we need to try it...

## How to run

### Clone the repo

```shell
git clone https://github.com/hasansezertasan/fastui-tutorials.git
cd fastui-tutorials
```

### Change directory to the example

```shell
cd examples/with-flask
```

### Run the application

```shell
uv run with-flask
```

Then open `http://127.0.0.1:8000`.
