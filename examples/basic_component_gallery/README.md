# Basic Component Gallery

This is a simple example that demonstrates how to use basic components like:

- `Text`
- `Paragraph`
- `Heading`
- `Code`
- `Iframe`
- `Image`
- `Spinner`
- `Button`
- `Link`
- `LinkList`

Other components used:

- `Navbar`
- `Page`
- `Div`

## How to run

### Clone the repo

```shell
git clone https://github.com/hasansezertasan/fastui-tutorials.git
cd fastui-tutorials
```

### Change directory to the example

```shell
cd examples/basic_component_gallery
```

### Run the application

```shell
uv run basic-component-gallery
```

Then open `http://127.0.0.1:8000`.
