# Page Example

> This example is explained step by step in the [tutorial](../../docs/tutorial/03-layout-and-titles.md).

This is a simple example that demonstrates how to use the `Page` component to create a simple layout.

Used Components:

- `Page`
- `Heading`

Used Events:

- ...

## How to run

### Clone the repo

```shell
git clone https://github.com/hasansezertasan/fastui-tutorials.git
cd fastui-tutorials
```

### Change directory to the example

```shell
cd examples/simple_layout
```

### Run the application

```shell
uv run simple-layout
```

Then open `http://127.0.0.1:8000`.
