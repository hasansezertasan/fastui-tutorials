# Personal Portfolio

This is a simple personal portfolio project built with FastAPI and FastUI.

It actually resembles a business card rather than a portfolio: a photo, a name,
a short bio, and links to GitHub, email, and the FastUI tutorials repository.

Used Components:

- `Heading`
- `Image`
- `Link`
- `LinkList`
- `Page`
- `Paragraph`
- `Text`

## How to run

### Clone the repo

```shell
git clone https://github.com/hasansezertasan/fastui-tutorials.git
cd fastui-tutorials
```

### Change directory to the example

```shell
cd examples/personal_portfolio
```

### Run the application

```shell
uv run personal-portfolio
```

Then open `http://127.0.0.1:8000`.
